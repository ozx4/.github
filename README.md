# .github

This repository holds the public profile of the [ozx4](https://github.com/ozx4) organization on GitHub.

GitHub shows `profile/README.md` on the organization's page to anyone who is not a member. Members see the members-only profile instead.

**This repository is public.** Put nothing here that is not ready for anyone to read: no solution names that have not cleared the brand screen, and no links to private repositories.

## What is here

| Path | What it is |
|---|---|
| `profile/README.md` | The Coming Soon page visitors see at github.com/ozx4 |
| `profile/assets/` | The images that page shows |

## Where the images come from

The banner is a copy of `logos/07-hero/drycraf-hero-banner-1500x500-3000x1000.png` from the brand folder of drycraf's private hub repository. The hub is the source. When a logo changes there, copy it here again.
